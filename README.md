# 영어 단어 받아쓰기 학습 도우미

초등 저학년 아이가 화면(그림/소리)을 보고 들으며 노트에 직접 스펠링을 적는
받아쓰기 테스트용 Streamlit 웹 앱입니다.

## 1. 준비물

- Python 3.9 이상
- Google Gemini API Key (단어장 OCR 및 뜻 자동 생성에 사용) — https://aistudio.google.com/apikey
  에서 무료로 발급 (카드 등록 없이 무료 사용량 한도 내에서 사용 가능)
- 인터넷 연결 (구글 TTS(gTTS) 음성 생성 및 Gemini API 호출에 필요)

## 2. 설치

```bash
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

## 3. API Key 설정 (둘 중 하나만 하면 됩니다)

**방법 A. 앱 실행 후 사이드바에 직접 입력** (가장 간단)
- 앱을 실행하면 왼쪽 사이드바에 "Google Gemini API Key" 입력창이 있습니다.

**방법 B. secrets.toml에 미리 저장**
```bash
mkdir -p .streamlit
cp .streamlit/secrets.toml.example .streamlit/secrets.toml
# secrets.toml 파일을 열어 본인의 API 키로 수정
```

## 4. 실행

```bash
streamlit run app.py
```

브라우저에서 `http://localhost:8501` 이 자동으로 열립니다.

## 5. 사용 순서

1. **단어장 등록**: 휴대폰으로 찍은 단어장 사진(또는 PDF)을 업로드하면 영어
   단어와 초등학생 눈높이의 한글 뜻이 자동으로 추출/생성되고, 1번부터
   번호가 매겨진 표로 보여줍니다. 표는 직접 수정할 수 있고, CSV 다운로드나
   구글 시트 붙여넣기용 복사도 가능합니다. (CSV 파일을 이미 갖고 있다면
   "CSV 파일 불러오기" 탭으로 바로 등록할 수도 있습니다.)
2. **테스트 설정**: 테스트할 번호 구간(예: 1~20번)과 문제 수를 입력하고
   "테스트 시작하기"를 누릅니다.
3. **받아쓰기 진행**: 문제마다 80% 확률로 영어 발음이, 20% 확률로 한글 뜻이
   음성/텍스트로 제시됩니다. 아이는 화면의 입력창이 아니라 실제 노트에
   정답 스펠링을 적습니다. "다시 듣기" 버튼으로 음성을 반복해서 들을 수
   있고, 20초 타이머가 다 되면 자동으로 다음 문제로 넘어가며, 버튼을
   누르거나 Enter를 치면 즉시 다음 문제로 넘어갑니다.
4. **정답 확인**: 테스트가 끝나면 출제 순서대로 [문제 번호 | 출제 방식 |
   정답(영어+한글)] 표가 한번에 나타나, 아이 스스로 또는 부모님이 채점할
   수 있습니다.

## 6. 참고 사항

- gTTS는 매번 새로 만든 음성을 세션 내에서 캐시하므로, 같은 단어를 다시
  들을 때는 API를 다시 호출하지 않습니다.
- OCR 결과(단어/뜻)가 정확하지 않을 경우, 등록 화면의 표를 직접 수정한 뒤
  "수정 내용 저장" 버튼을 눌러 반영할 수 있습니다.
- 인터넷이 없는 환경에서는 gTTS(음성 생성)와 Gemini API(OCR/뜻 생성)가
  동작하지 않습니다.
- Gemini 무료 등급은 분당/일일 요청 수 제한이 있습니다. 짧은 시간에 너무
  많이 시도하면 일시적으로 오류가 날 수 있으니, 잠시 후 다시 시도해주세요.
